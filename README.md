
# DRL-Based Power Control in Underlay Cognitive Radio Networks

This repository contains my implementation of a research paper on actor-critic-based deep reinforcement learning for power control in underlay cognitive radio networks.

## Overview

The project explores the use of Deep Reinforcement Learning (DRL) for transmit-power allocation in underlay cognitive radio networks.

## Modifications and Extensions

- Alternative reward function formulation.
- Imperfect Channel State Information (CSI).
- Correlated channel fading.

## Reference

[Actor-critic based deep reinforcement learning framework for underlay communication](https://doi.org/10.1007/s11276-026-04161-z)
